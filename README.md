English to German Translator (Streamlit + OpenAI)

This is a simple Streamlit web app that translates English text into German using the OpenAI API.
The assistant is constrained to only perform translation and ignore other instructions.

Features

Streamlit chat interface

Automatic English → German translation

Conversation history stored in session state

API key loaded securely from a .env file
